# Fonts

Latin-subset WOFF2 files from Fontsource 5.3.0 (`@fontsource-variable/sora`,
`@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono`), self-hosted so the
build does not depend on Google Fonts.

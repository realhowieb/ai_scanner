# User experience round (2026-10-23)

Five changes for users of the web app.

| What | Where | Off switch |
|---|---|---|
| Getting started checklist at the top of Today (save stocks, first alert, alerts on your phone or confirm email, how the score works). Ticked from what the account did; hides when all 4 are done or the user clicks "Hide this". | `api/web_state.py`, `GET /v1/me/getting-started`, `web/src/features/GettingStarted.tsx` | `HSF_GETTING_STARTED=0` on hsf-api-v1 |
| Red count on the Alerts tab for alerts fired since the Alerts page was last opened (first time: last 7 days). | `GET /v1/me/alerts/unread`, `POST /v1/me/alerts/seen`, `web/src/components/AlertsBadge.tsx` | none needed |
| Link previews: a site-wide preview image, and a public page per stock at `/share/{TICKER}` with its own preview card. Ranked stocks show HSF Score, setup and the first reason; the rest needs an account. Signed-in visitors are sent to `/stocks/{TICKER}`. A Share button on the stock page makes the link, with the user's invite code. | `GET /v1/public/stocks/{ticker}` (`api/share.py`, rate limit `share` per IP), `web/src/app/share/[ticker]/`, `web/src/app/opengraph-image.tsx`, `web/src/features/ShareStock.tsx` | remove the Share button |
| Send feedback (account menu and page footer). Stored in `hsf_feedback`, sent to the admins' Telegram/Discord, emailed when none is linked. Listed on Admin > Users > Feedback from users. | `POST /v1/me/feedback` (10 per hour per account), `GET /v1/admin/feedback`, `web/src/components/FeedbackDialog.tsx` | `HSF_FEEDBACK_NOTIFY=0` stores without messaging |
| Analytics: new PostHog events `getting_started_step_opened`, `getting_started_dismissed`, `feedback_sent`, `stock_shared`, `checkout_completed`, `ask_hsf_asked`. Sign-up, watchlist and checkout-started events already existed. | `web/src/lib/usageAnalytics.ts` | the user's Account setting, as before |

Tables (created on first use): `hsf_web_state` (one row per account) and `hsf_feedback`.

Preview links use `https://app.hsfinest.com` unless `NEXT_PUBLIC_SITE_URL` is set on hsf-web-v1 at build time.

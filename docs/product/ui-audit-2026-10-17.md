## API compatibility

`GET /v1/sparklines` adds optional `last_bar` entries with a finite daily-bar value and the provider session date. Existing `series` consumers remain compatible. Undated indexes never receive invented dates. Daily bars may include the session in progress and are labeled accordingly. The existing batched provider request and cache are reused; no per-ticker requests were added. OpenAPI and TypeScript types are regenerated together.

## Limits

This is not a WCAG certification or a full assistive-technology/zoom audit. Fixture-based layout checks do not certify production data or market-open behavior. Real purchases, cancellation, alert delivery, paper fills, credential changes and maintenance actions were not performed. API responses that lack quote timestamps remain explicitly labeled; missing timestamps are not inferred. History filters describe the loaded 50-run scope.
